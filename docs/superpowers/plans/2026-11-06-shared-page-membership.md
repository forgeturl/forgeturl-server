# 将共享页面加入我的空间

基线：后端 `1b910c4`，前端 `61eef78`。遵循本次用户提供的开发方案，直接在当前分支实现并验证。

## 接口和数据

- 复用 `user_page`，精确保存打开的 R/E/A 分享 ID，不复制页面或创建链接。
- `addSharedPage(page_id)` 返回 `page_brief`、`page_ids`、`already_added`。本人页面返回所有者入口，不重复关联。
- `removeSharedPage(page_id)` 只删除登录用户的关联，物理删除兼容旧软删除记录；返回 `page_ids`，允许空列表。
- 对同一用户的加入、移除、创建和排序在事务内锁住 user 行；分享查询锁住 page 行以协调撤销。
- 排序新增 `base_page_ids` 和 `check_base`：旧列表不匹配时报冲突；旧客户端省略基线时保留未提交的已有入口，避免覆盖新加入项。删除共享入口统一使用独立接口。
- 撤销分享保留关联；getMySpace 仅将 NotFound 转成无权限占位，其余数据库错误正常返回。

## 实现步骤

1. 后端验证与持久化：为非法 ID、幂等追加、软删除后重加、仅删除本用户、空列表及旧排序冲突编写行为测试；实现 `app/dal/shared_page.go` 和 `app/api/shared_page.go`，更新 `space.go`、`page_tool.go`、`conf/const.go`。
2. Proto：更新 `app/api/proto/space.proto`，检查 protoc 24.2、定制 Go 插件及 Go 1.24.11 后运行现有 `app/genapi.sh`，不手改生成代码。
3. Store：在 `src/utils/pageState.js`、`src/api/space.js` 加入独立 action；成功后合并完整顺序，未知摘要保留占位，失败不改状态；处理过期响应、退出登录、失效内容清理。用延迟请求测试状态及竞态。
4. 页面：共享页顶部添加登录/加入/已加入/打开入口，保留权限标签；`/my?page_id=...` 定位；桌面和移动列表增加权限标签和移除按钮。复用 autoSave 与编辑器导航保护；失效页显示提示、允许移除。
5. 登录：在现有 OAuth 流程使用 sessionStorage 保存经过本地路径校验的 redirect，兼容微信跨域回传；回调后返回原分享页。
6. 验证：前端完整测试、生产构建；后端完整 Go 测试和构建；用模拟 API 进行桌面/移动浏览器回归，覆盖共享编辑、只读、重试、移除、空列表、撤销及原加号/单条/批量/导入行为。
7. 对照需求和仓库规范复查，提交并推送当前开发分支。记录真实验证范围及部署状态。

## 重点回归

- 延迟的空间/页面响应不能复活失效内容或已移除入口。
- 只读权限始终由后端 page_conf 决定，列表关联不赋予所有权。
- 摘要刷新失败不能将成功加入转换为失败。
- 待保存失败时，加入/跳转/移除不能丢失编辑内容。
- 并发加入、创建和旧排序不能互相覆盖。

持久化新增测试使用 SQL mock / DryRun，不连接实际数据库、不增加默认迁移或表结构操作。浏览器使用模拟数据，不操作线上账号。
